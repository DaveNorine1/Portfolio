Measuring lift with matched-market tests

At a medical device division I built the test-and-learn practice: A/B testing set up with IT and Legal, and matched-market tests run with IT, Finance, Sales, and Field Marketing to measure the lift from local campaigns. Here's how I run one and how I turn the read into a decision.

Why geo tests

A geo test needs no user-level tracking and gives a real control group. That makes it the best answer I know of when consent limits tracking and a campaign can't be randomized person by person. The hard part is reading the result honestly, because a handful of markets carries little statistical power.

Demo: a worked example on made-up data

My real test results stay private, and everything from here down is simulated. This simulation uses 40 markets over 86 weeks, with a campaign that truly lifts leads by 7.3% in test markets for 8 weeks. Here's the process:

  • Match: pair markets on level and shape over the first 52 weeks.
  • Check: keep the 4 pairs that track each other best on the next 26 weeks, which matching never saw.
  • Assign: flip a coin within each pair to choose the test market.
  • Estimate: use difference-in-differences on log leads, by pair.

Demo: how sure can we be?

A simple t-interval says the lift is 4.8% to 8.0%. That test is fine on average: run on the 16 untreated pairs in the same window, 4,000 random draws produced false positives 5.5% of the time, close to the expected 5%. But the width of any single interval rests on three degrees of freedom, and these four pairs happen to agree more than pairs usually do. So I took the noise level from those untreated draws, which is wider.

Using that noise and a weakly skeptical prior centered on zero, the Bayesian estimate of the lift is 6.0%, with a 95% range of 1.2% to 11.1%. With four pairs, an exact randomization test also can't get below p = 0.125. Four pairs can show direction, but they can't settle a close call.

My call on this demo: don't scale it as is. The campaign very likely works, and it probably doesn't pay for itself at this spend. A report that stopped at "significant lift" would have sent more money after it. I'd rerun at a lower spend per market with more pairs. Power to tell a lift of this size from zero climbs from 44% at 4 pairs to 96% at 8. Showing that it clears the payback line is a harder test, and it would need a new power estimate at the new spend.

The simulation lets me check the answer: the true lift of 7.3% falls inside the range, and the point estimate of 6.4% landed close to it.

The code

def pair_effect(log_leads, treated, control, pre, post):
    #difference-in-differences on logs, so the effect reads as an approximate percent lift
    t = log_leads[treated, post].mean() - log_leads[treated, pre].mean()
    c = log_leads[control, post].mean() - log_leads[control, pre].mean()
    return t - c

def normal_posterior(mean, se, prior_mean=0.0, prior_sd=0.10):
    #conjugate normal update with a skeptical prior centered on no effect
    precision = 1 / prior_sd**2 + 1 / se**2
    post_mean = (prior_mean / prior_sd**2 + mean / se**2) / precision
    return post_mean, np.sqrt(1 / precision)
