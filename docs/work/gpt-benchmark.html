GPT from scratch, with GPU instrumentation

I wrote a decoder-only Transformer in PyTorch and instrumented its training as a GPU benchmark. On an A100, the 202-million-parameter model trained at about 113,000 tokens per second, holding that pace for all 10,000 steps.

What I built

  • Causal self-attention, Transformer blocks, and the full training loop, written directly in PyTorch.
  • Mixed precision, gradient accumulation, checkpointing, and model sizes that adapt to available GPU memory.
  • CUDA event timing, step-latency distributions, and GPU utilization, power, and temperature logging.

What the loss curve says

This is a stress test and not a useful text generator. A model this size memorizes a small dataset like Tiny Shakespeare, so training loss reached 0.03 while validation loss rose to 4.69. For real generation, I'd stop near step 750, use a smaller model, or train on much more data.

The code

class CausalSelfAttention(nn.Module):
    def __init__(self, cfg):
        super().__init__()
        if cfg.n_embd % cfg.n_head != 0:
            raise ValueError("n_embd must be divisible by n_head")

        self.n_head = cfg.n_head
        self.head_dim = cfg.n_embd // cfg.n_head
        self.dropout = cfg.dropout

        self.qkv = nn.Linear(
            cfg.n_embd,
            3 * cfg.n_embd,
            bias=cfg.bias,
        )
        self.projection = nn.Linear(
            cfg.n_embd,
            cfg.n_embd,
            bias=cfg.bias,
        )
        self.residual_dropout = nn.Dropout(cfg.dropout)

    def forward(self, x):
        batch, sequence, channels = x.shape

        q, k, v = self.qkv(x).split(channels, dim=2)

        q = q.view(
            batch,
            sequence,
            self.n_head,
            self.head_dim,
        ).transpose(1, 2)

        k = k.view(
            batch,
            sequence,
            self.n_head,
            self.head_dim,
        ).transpose(1, 2)

        v = v.view(
            batch,
            sequence,
            self.n_head,
            self.head_dim,
        ).transpose(1, 2)

        # PyTorch dispatches to an optimized attention implementation when possible.
        attention = F.scaled_dot_product_attention(
            q,
            k,
            v,
            attn_mask=None,
            dropout_p=self.dropout if self.training else 0.0,
            is_causal=True,
        )

        attention = attention.transpose(1, 2).contiguous().view(
            batch,
            sequence,
            channels,
        )

        return self.residual_dropout(self.projection(attention))
