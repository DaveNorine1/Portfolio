Taking an AI agent from pilot to daily use

As my division's AI Champion, I built a retrieval-based AI agent for a small patient engagement team that works as an inbound patient contact center. The team uses it daily. It delivered a double-digit drop in onboarding time and saves real working time every week.

The situation

The team's answers lived in dozens of approved decks, FAQs, and scripts. In a patient-facing setting, an assistant that makes something up is worse than having no assistant.

What I did

  • Met with the team's leadership to define what the agent had to do.
  • Confirmed licensing with IT before investing build effort.
  • Brought in Legal, Privacy, and IT as governance partners.
  • Grounded every answer in the approved documents through retrieval.
  • Ran a structured pilot and tested its answers before launch.
Result: used daily by the team, with a double-digit drop in onboarding time and working time saved every week.

Demo: a support agent you can inspect

The real agent and documents are private, so everything from here down is a separate demo for a made-up company, Larkfield Water. I built it with LangChain, LangGraph, Chroma, and Gradio, and tested it with Llama 3.1 on a GPU.

The design keeps control in code:

  • Safety first: health and urgent questions go to a person before retrieval runs.
  • Find the source: sentence embeddings find the right documents.
  • Approved words only: the model picks a sentence, code confirms it's in the document, and the customer reads that sentence with its citation.
  • Know when to stop: if nothing checks out, it declines and points to a lead.

The code

The check every answer has to pass, from the repo:

def verify(result, passages):
    #returns the approved sentence itself, so nothing the model wrote reaches the customer
    source = result.get("source")
    text = " ".join(p["text"] for p in passages if p["source"] == source)
    quote = normalize(str(result.get("quote", "")))
    if not text or not quote:
        return None
    best, score = None, 0.0
    for sentence in sentences(text):
        ratio = difflib.SequenceMatcher(None, quote, normalize(sentence)).ratio()
        if ratio > score:
            best, score = sentence, ratio
    #small copying slips are fine, a sentence that isn't in the document isn't
    return (source, best) if score >= 0.8 else None
